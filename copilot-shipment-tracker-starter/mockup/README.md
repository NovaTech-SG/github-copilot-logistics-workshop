# 新增本机保存与确认的效果稿

直接用浏览器打开 [index.html](index.html)，不需要服务、凭据或网络。它沿用现有异常队列布局，重点展示右侧新增功能完成后的状态。

| 已有基础 | 本次新增 |
|---|---|
| 查询、数量概览、筛选搜索、分页与详情 | 按异常编号保存状态和备注到本机 |
| 源状态和本机记录的展示位置 | 保存后重新读取、核对并反馈结果 |
| SQLite 表结构、规则校验和 overlay | 过期提交检查、持久化与失败反馈 |

示例表示一条源 OPEN 异常已在本机改为 IN_PROGRESS，所以静态统计从源状态 40 / 69 / 60 变成 39 / 70 / 60。全部 169 条和页面中的队列记录仅为效果示意；它们不是实际查询或保存结果。

控件不可操作，页面没有 JavaScript，不访问 MCP，也不写 SQLite。学员按 [课堂提示词](../docs/prompts.md) 生成新功能规格，再在真实应用里完成两处 TODO 和必要测试。
