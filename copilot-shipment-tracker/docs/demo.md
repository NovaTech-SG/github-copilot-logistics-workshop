# Spec Kit讲师演示入口

先按[Spec Kit课堂操作](speckit.md)检查版本与活动功能，命令见[prompts.md](prompts.md)。本目录用于完成效果复盘；生成和实现演示在学员项目进行。

# 讲师演示安排

## 课前

分别打开完成版与学员项目，完成版8768、学员项目8769。确认MCP能读培训表，空本地库源分布为169/40/69/60。为每轮演示指定新的--db文件，保留已有练习记录。

## 课堂15分钟

1. 2分钟看效果：选OPEN异常，改为IN_PROGRESS并填写备注，保存后刷新或重启确认。
2. 3分钟读Spec和项目规则：让Copilot解释状态流转和本地保存边界，再列改动文件与验收方式。
3. 6分钟跟练：在学员项目实现store.save，以及表单提交、重新读取、成功/失败反馈。
4. 4分钟验收：状态和备注保留，空备注不保存，OPEN不能直接RESOLVED；确认源记录状态未变。

学员使用docs/prompts.md按阶段推进，不读取相邻完成版。本地存储和MCP连接均预置，不在课堂安装工具或新建云端权限。

## 后续10分钟协作环节

复盘一次失败，运行测试、检查diff，核对仅含练习改动和无凭据。再简要演示提交、PR文件差异和CI结果。当前CI配置只运行离线测试与JavaScript语法检查，不访问Databricks、不部署服务器。推送和创建PR前按实际仓库与分支确认范围。
