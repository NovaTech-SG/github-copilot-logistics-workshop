# Feature Specification: 物流承运商Dashboard

**Feature Branch**: `main`（本次未创建分支，活动功能由.specify/feature.json选择）
**Created**: 2026-11-09
**Status**: Ready for classroom implementation
**Input**: 物流同事希望按承运商查看运输表现，比较准时率，并筛选需要跟进的承运商。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 查看与筛选运输表现 (Priority: P1)
物流同事查看运输总量、有效分母、准时率和延误量，再选择承运商，核对各组件的范围。可以清除筛选回到全部。

**Why this priority**: 这是15分钟课堂要实现的业务功能。
**Independent Test**: 全部、CAR002和空范围分别核对；清除筛选后恢复整体。
**Acceptance Scenarios**:
1. **Given** 全部培训运输数据，**When** 查看指标，**Then** 总量500、有效380、准时304、延误76、准时率80.00%。
2. **Given** 选择CAR002，**When** 完成查询，**Then** 总量134、有效104、准时77、延误27、准时率74.04%，指标、对比图及已有明细范围一致。
3. **Given** 没有有效分母，**When** 显示准时率，**Then** 显示N/A，不能显示0%。
4. **Given** 数据读取失败，**When** 查询结束，**Then** 明确显示错误并允许重试，旧结果不伪装为本次结果。

### User Story 2 - 查看趋势与分页明细 (Priority: P2)
物流同事按业务日期观察每日运输量，并分页查看运输单。

**Why this priority**: 作为课后扩展；不得挤占P1跟练。
**Independent Test**: 趋势合计等于所选范围单量，相邻明细页无重复。
**Acceptance Scenarios**:
1. **Given** CAR002，**When** 每页20条查看明细，**Then** 共7页、末页14条。
2. **Given** 整体数据，**When** 查看趋势，**Then** 覆盖65个自然日，缺失自然日补零，合计500。

### Edge Cases
- 实际与计划到达时间相等，计为准时；已送达但缺少任一到达时间的记录排除。
- 在途、已取消、零有效分母和空范围分别处理，不能用假数据掩盖失败。
- 同一运输单可以有多条异常，统计运输量时避免一对多关联重复计数。

## Requirements *(mandatory)*

### Functional Requirements
- **FR-001**: 显示总量、有效分母、准时率和延误量，数值来自获授权的培训数据源。
- **FR-002**: 有效分母仅含DELIVERED且计划与实际到达时间完整的运输单。
- **FR-003**: 实际到达不晚于计划即准时，相等算准时；延误=有效-准时，排除=总量-有效。
- **FR-004**: 总准时率以总准时量除以总有效分母计算，零分母返回空值并显示N/A。
- **FR-005**: 支持承运商筛选和清除筛选，所有已实现组件采用同一数据范围。
- **FR-006**: 查询未完成时等待完成；连接失败、结果不完整时明确提示，不以固定答案替代。
- **FR-007**: 明确标识培训模拟数据，凭据不出现在页面、业务输出或提交中。
- **FR-008**: P2趋势按shipment_date补齐自然日；每页20条，筛选改变回第1页。
- **FR-009**: P2数据快照与本次查询时间分别标注，显示时区为Asia/Shanghai。
- **FR-010**: 为指标边界、筛选一致性和失败反馈保留可重复检查与实际操作记录。

### Key Entities
- Shipment：一条运输单，shipment_id唯一，包含承运商、业务日期、计划与实际到达时间、状态。
- Carrier：一个模拟承运商，carrier_id唯一。
- Scope：本次全部或指定承运商范围；验收答案不作为业务数据来源。

## Success Criteria *(mandatory)*

### Measurable Outcomes
- **SC-001**: P1全部和CAR002结果分别符合上述验收值，清除筛选恢复全部。
- **SC-002**: 零有效分母显示N/A；连接失败时不显示伪造成功结果。
- **SC-003**: 学员能说明分子、分母与排除条件，并给出实际运行的验证记录。
- **SC-004**: P2明细、趋势分别满足分页与合计要求；未实现时如实列为扩展。

## Assumptions
- 业务规则为本课明确的教学约定，不代表Nike生产政策；全部数据为模拟数据。
- 课堂身份、源数据和运行环境已在课前准备；无法访问时应先处理连接条件。
- 全部/承运商验收详细值见acceptance.md；实现不得硬编码这些答案。
- 本功能限定本地应用，不包含服务器部署。

## Clarifications
### Session 2026-11-09
- Q: 在途、已取消或缺少实际到达时间的单量进入准时率分母吗？ → A: 不进入；规则以FR-002为准。
- Q: 分母为零如何显示？ → A: N/A，表示不适用，不等同0%。
- Q: 15分钟是否需要做完趋势和分页？ → A: P1先完成，P2留作课后扩展。
以上答案来自已确认培训规格，非虚构的现场学员回答。
